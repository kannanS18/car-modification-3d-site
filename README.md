# 🏎️ AUTOFORGE — 3D Motorsport & Car Modification Atelier

A high-performance 3D automotive website built with **React Three Fiber**, **Three.js**, **Framer Motion**, and **Tailwind CSS**.

Featuring a real **Ferrari 458 Italia 3D model** with live PBR paint customizer, wheel finish selectors, neon underglow, spark embers, dyno specs, and build commission booking.

### Quick Start
```bash
npm install
npm run dev
```
Visit `http://localhost:3001`
